# Study Plans

This core repo keeps only platform-neutral templates.

Domain study plans live in sibling content repos listed in `content-sources.json`:

- `open-education-cybersecurity`
- `open-education-data-science`
- `open-education-game-development`
- `open-education-software-development`

Add new subject plans in the matching content repo, then update the suite ingestion contract if the platform needs new metadata.
