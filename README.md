# Open Education Suite

A modular, open-source toolkit designed to help anyone learn anything.  
This suite provides tools for generating study materials, building structured learning plans, and discovering high-quality free educational resources.

## Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/yourusername/open-education-suite
cd open-education-suite
```

### 2. Explore the Tool Suite
Each tool lives under tools/ and includes its own documentation.

### 3. Create Your First Study Plan
Use the template in study-plans/templates/study-plan-template.md.
