# Product Context

## Users
- Learners using an adaptive teacher and local learner workspace.
- Owner/operator reviewing content health, learner blockers, generated lecture readiness, and QA evidence.
- Content authors maintaining subject-specific `open-education-*` repos.

## Core value
The platform turns reusable subject content into adaptive teaching workflows while keeping provenance, learner-state evidence, and privacy visible.

## Current validation posture
- Deterministic local checks are preferred before live model calls.
- QA Live is used for automatable UI/runtime validation.
- Manual validation is limited to subjective teaching quality, creative media judgment, private credentials, or external hosted settings.

## Quality bar
- Learners should know what to do next, why it was selected, what source is being used, and what evidence changed mastery.
- Operators should be able to audit every state or content-health decision.
