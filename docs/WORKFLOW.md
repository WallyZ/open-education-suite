# Workflow Overview

This document outlines the recommended workflow for using and contributing to the Open Education Suite.

---

## 1. Ingest Content

- Add PDFs, ebooks, or URLs to the appropriate folder  
- Use tools in `tools/pdf-to-anki/` or `tools/summarizers/`  
- Generate summaries, flashcards, or quizzes  

---

## 2. Generate Study Materials

- **[Flashcards](guide://action?prefill=Tell%20me%20more%20about%3A%20Flashcards)** using the PDF → Anki pipeline  
- **[Summaries](guide://action?prefill=Tell%20me%20more%20about%3A%20Summaries)** for quick review  
- **[Quizzes](guide://action?prefill=Tell%20me%20more%20about%3A%20Quizzes)** for self-testing  

---

## 3. Build a Study Plan

- Start with the template in `study-plans/templates/`  
- Define goals, resources, milestones, and review cycles  
- Add flashcards and quizzes to reinforce learning  

---

## 4. Review & Iterate

- Update decks as you learn  
- Add new resources  
- Track progress and refine your plan  

---

## 5. Share & Contribute

- Submit PRs with new tools, study plans, or curated resources  
- Improve documentation  
- Help expand the suite for all learners
