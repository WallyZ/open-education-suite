# Architecture Overview

The Open Education Suite is built around a modular, extensible architecture.

---

## Core Layers

### 1. Input Layer
Handles ingestion of:
- PDFs  
- Ebooks  
- Web articles  
- Transcripts  

### 2. Processing Layer
Includes:
- Chunking  
- Summarization  
- Flashcard generation  
- Quiz generation  

### 3. Output Layer
Produces:
- Anki decks  
- Markdown notes  
- Study plans  
- Resource lists  

### 4. Orchestration Layer
Optional integrations:
- CLI tools  
- Discord bots  
- Automation scripts
