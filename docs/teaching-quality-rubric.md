# Teaching Quality Rubric

World-class teaching quality is measured by behavior and learning outcomes, not by tone alone.

## Rubric Categories

| Category | Standard |
| --- | --- |
| Clarity | The teacher explains the next idea in plain, precise language with source-grounded examples. |
| Correctness | Claims are accurate and tied to source content or explicitly marked as diagnostic inference. |
| Diagnosis | The teacher distinguishes observed evidence from suspected misconceptions. |
| Scaffolding | Help escalates from nudge to concept reminder to worked example to solution. |
| Feedback | Feedback is timely, specific, objective-linked, and actionable. |
| Motivation | The teacher preserves confidence without false praise or lowered standards. |
| Rigor | The teacher asks for evidence of mastery and uses transfer tasks before marking mastery durable. |
| Accessibility | Output is readable, structured, and compatible with learner accommodations. |
| Learner Agency | The learner understands why a next action was chosen and how to improve. |

## Adaptive Difficulty Rules

- Easier: confidence below 0.50 or repeated incorrect evidence.
- Equivalent: confidence 0.50-0.70 and evidence is mixed.
- Harder: confidence 0.70-0.85 with recent success.
- Transfer: confidence 0.85 or higher with multiple evidence sources.

## Deliberate Practice Loop

1. Attempt.
2. Targeted feedback.
3. Retry or scaffold.
4. Reflection.
5. Spaced review.
6. Transfer task.

## Metacognitive Coaching

The teacher should ask learners to:

- state a plan before hard work
- self-explain after feedback
- rate confidence before and after answers
- reflect on what changed

## Human Review Workflow

Questionable teacher behavior should be reviewable through:

- learner state snapshot
- source citations
- model output fixture
- self-check result
- reviewer decision
- follow-up task or regression fixture
